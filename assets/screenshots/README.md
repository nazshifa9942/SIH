# Project Screenshots

Store the important screenshots of the NavSetu application in this folder.

## Contents

The `Screenshot 2026-08-27 *.png` files in this folder show the main application screens (dashboard, cargo workspace, vessel and port management, map, market analytics).

## Recommended screenshots

- Home / landing screen
- Main command dashboard
- Cargo workspace workflow (forecast, cost, risk, optimization, recommendation)
- Vessel tracking map
- Final recommendation output

## Naming convention

Use clear names such as:

- `01-home.png`
- `02-dashboard.png`
- `03-cargo-workspace.png`
- `04-map.png`
- `05-recommendation.png`

Do not upload screenshots containing passwords, API keys, tokens, personal credentials, or other sensitive information.

## Adding screenshots to README

You can display important screenshots in the main `README.md` using a relative path, for example:

```md
![Command Dashboard](assets/screenshots/02-dashboard.png)
```
