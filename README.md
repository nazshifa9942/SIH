# SIH26006

Intelligent Freight Forecasting and Vessel Chartering Recommendation System.

The `/docs` directory is the single source of truth for architecture, schema, API contracts, and AI collaboration rules.

Backend implementation lives in `/backend` (JavaScript, Node.js, Express, Prisma, PostgreSQL).

See `backend/README.md` for local run instructions.
